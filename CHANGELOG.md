## [0.2.0] - 2026-08-02

### Added

- Added cookie-authenticated, headless browser image fetching from torrent comment links.
- Added configurable minimum image dimensions and maximum image count.
- Added a cache-first, paginated image gallery with static and animated image support.
- Added image-fetch progress and error reporting through the native Qt status bar.
- Added configurable torrent-tag extraction and linked tag display.
- Added `CHANGELOG.md` following Keep a Changelog conventions.
